# Smart City Governance 🏙️

A full-stack web application built to support smart city administration and governance through a centralized digital platform. The project uses **Java** for backend development and **React.js** for the frontend.

## 🚀 Project Overview

Smart City Governance aims to provide a digital platform for managing city-related services and administrative activities. It demonstrates the integration of a Java backend with a React frontend to build a structured and interactive web application.

## ⚙️ Getting Started

### Prerequisites

Make sure you have installed:

- Java JDK
- Node.js and npm
- MySQL
- Maven (or use the included Maven wrapper)

### Backend Setup

1. Navigate to the backend directory:

```bash
cd backend
```

2. Configure your MySQL database and environment variables.

3. Run the Spring Boot application:

**Windows:**
```bash
mvnw.cmd spring-boot:run
```

### Frontend Setup

1. Open another terminal.
2. Navigate to the frontend directory:

```bash
cd frontend
```

3. Install dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm run dev
```

## 🔐 Configuration

Configure the required database, JWT, and email environment variables before running the backend.

Do not commit passwords, API keys, JWT secrets, or other sensitive credentials to GitHub.
